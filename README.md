# Kokoa Clone · 여러 화면 실습

HTML·CSS로 메신저의 여러 화면을 구성한 UI 학습 프로젝트입니다.

## 구성

- `index.html`: 시작 화면
- `friends.html`: 친구 목록
- `chats.html`, `chat.html`: 채팅 목록과 대화 화면
- `find.html`, `more.html`, `settings.html`: 탐색·더보기·설정 화면
- `css/`: 공통 및 화면별 스타일
- `screenshot/`: 화면 이미지 자료

## 확인 방법

저장소를 내려받아 브라우저에서 `index.html`을 엽니다. 외부 아이콘 등 연결된 리소스는 인터넷 연결이 필요할 수 있습니다.

화면 구성 학습용이며 실제 메신저 서비스의 로그인·메시지 전송 기능을 제공하는 프로젝트는 아닙니다.
